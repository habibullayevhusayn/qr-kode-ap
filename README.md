# Yoz QR Android app

The web app remains a small HTML/CSS/JavaScript app. Capacitor supplies the Android APK wrapper and the native Android bridge for saving QR images to the gallery and scheduling local reminders.

## Build an APK with GitHub Actions

1. Push the repository to GitHub.
2. Open the repository's **Actions** tab and run **Build Android APK** (the workflow also runs on pushes).
3. When the run finishes, open it and download the `yoz-qr-android-apk` artifact.
4. Transfer `app-debug.apk` to the phone and install it. Android may ask you to allow installing apps from that source.

The workflow builds an installable **debug APK**, not a Play Store-signed release.

## Android features

- Tap **QR kodni saqlash** under a generated code to write its PNG into `Pictures/Yoz QR` in the phone gallery.
- Enable notifications in **Sozlamalar**. Android asks for notification permission; reminders are then scheduled locally on the phone every two hours and restored after a reboot.
- Android may delay inexact alarms because of battery optimization. The reminders are local notifications, not remote/server push notifications.

On GitHub Pages or another regular browser, saving falls back to a normal PNG download and reminders run only while the page is open.

## Local web checks

Install Node.js 22 or newer, run `npm ci`, then `npm run check`. The Android project is generated by the GitHub workflow and intentionally is not committed.
